SWAGGA — ИИ-гадалка для Telegram

ВАЖНО О БЕЗОПАСНОСТИ
- Никогда не отправляйте токен Telegram или API-ключ OpenAI в переписку.
- Ранее опубликованные ключи нужно отозвать и заменить.
- Добавляйте секреты только в Environment Variables на Render.

ЧТО ВНУТРИ
- main.py — программа бота
- requirements.txt — библиотеки
- render.yaml — настройки сервиса Render

ЗАПУСК С IPHONE (через GitHub + Render)
1. Распакуйте ZIP в приложении «Файлы» на iPhone.
2. В Safari откройте github.com и войдите в аккаунт.
3. Создайте новый репозиторий с именем SWAGGA (лучше Private).
4. Откройте репозиторий → Add file → Upload files.
5. Загрузите СОДЕРЖИМОЕ папки SWAGGA_AI_Bot: main.py, requirements.txt, render.yaml, README_RU.txt. Не загружайте ZIP как единственный файл.
6. На Render создайте Blueprint / New → Blueprint и подключите этот GitHub-репозиторий.
7. Добавьте переменные окружения:
   TELEGRAM_BOT_TOKEN = новый токен от BotFather
   OPENAI_API_KEY = новый API-ключ OpenAI
   OPENAI_MODEL = gpt-6-luna (можно оставить значение из render.yaml)
8. Нажмите Deploy. Не публикуйте значения секретов и не присылайте их в чат.

ОПЛАТА
- API OpenAI оплачивается отдельно от подписки ChatGPT; стоимость зависит от числа и длины запросов.
- Render Worker на плане Starter платный. Проверьте актуальную стоимость в Render до подтверждения.
- Не включайте платный сервис, пока не проверили тариф и лимиты расходов.

ПРИМЕЧАНИЕ
SWAGGA делает развлекательные символические предсказания, а не реальные гарантии будущего.
